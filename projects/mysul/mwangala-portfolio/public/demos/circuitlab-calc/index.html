Engineering reference

Formulas, units, assumptions, and limitations — the same notes attached to every saved calculation.

Ohm's law — V = I × R

Assumes linear resistive DC behaviour at constant temperature. Rejects negative magnitudes; R = 0 with V ≠ 0 is a short-circuit (undefined current) and is refused with an explanation.

Power — P = V·I = I²R = V²/R

DC resistive power. Units: W (mW, kW). Same input rules as Ohm's law.

Series — R = ΣRᵢ · Parallel — 1/R = Σ1/Rᵢ

Ideal resistors, no tolerance stacking shown. A zero resistor in parallel means a short: total 0 Ω (stated explicitly).

Voltage divider — Vout = Vs·R₂/(R₁+R₂)

Unloaded-divider model only: assumes no load current drawn from the output node. Loaded dividers need nodal analysis (future module).

Kirchhoff 2-mesh solver

Supported topology: two clockwise meshes sharing R₃; V₁ in mesh 1 (+ to − clockwise), V₂ in mesh 2. Equations: (R₁+R₃)I₁ − R₃I₂ = V₁ and −R₃I₁ + (R₂+R₃)I₂ = −V₂. Solved by Cramer's rule; singular systems (det ≈ 0) are reported as invalid/underdetermined, not silently answered. This is an educational tool, not SPICE.

Limitations

DC resistive circuits only. No reactive (L/C), AC phasor, temperature, or tolerance analysis yet. Results are rounded for display; stored values keep full precision with units attached.
