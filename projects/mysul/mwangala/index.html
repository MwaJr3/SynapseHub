Flagship Project

SentinelCore — Mini-SIEM Security Dashboard

A security monitoring platform that ingests events, normalizes security data, applies detection rules, correlates related events, and supports incident investigation. This is what I can build when multiple skills come together.

Problem: single-source log analysis doesn't match how defence works — analysts need many sources in one model with rules, correlation, and investigation workflow.

Solution: modular ingestion, a common event schema, transparent rules, grouped alerts with timelines, and incident management with role-based access and audit logging.
